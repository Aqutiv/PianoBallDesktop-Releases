# PianoBall Desktop

A Windows piano playground with recorded instruments, lessons and a recording
studio. This repository contains public downloads; application source is private.

**[Download the Windows x64 installer](https://github.com/Aqutiv/PianoBallDesktop-Releases/releases/latest/download/Aqutiv.PianoBallDesktop-win-x64-preview-Setup.exe)**

[Release notes and files](https://github.com/Aqutiv/PianoBallDesktop-Releases/releases/latest)

## Install and play

Run the installer from the Windows account that will use PianoBall, then launch
PianoBall Desktop Preview from the desktop or Start menu. Each Windows account
installs its own app. The preview is unsigned; Windows may show an
unknown-publisher warning. Use the official download link above.

Start with built-in sounds, or open **Settings → Sound library** to download
recorded instruments. Choose **Everyone on this PC** to share one copy of the
sounds, with administrator approval, or **Only me** for personal packs.
Restart PianoBall to activate new sounds. Settings, progress and recordings remain
private to each Windows account.

## Updates and offline use

Use **Settings → Updates → Check now**. You choose when to download and restart;
Later and Skip this version are available. Automatic checks can be turned off.

Installed instruments, built-in sounds and starter/cached lessons work offline.
For another offline PC, transfer the installer and any desired `.pbpack` files
from [the sound-pack releases](https://github.com/Aqutiv/PianoBallDesktop-Releases/releases)
by USB. Install the matching current app, then choose **Import packs** in the
Sound library and select the folder containing those files.

Removing an individual app installation preserves the shared sound library.
